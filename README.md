# Memory Lab 2

Полноценный мобильный PWA-тренажёр памяти. Работает без сервера и подходит для GitHub Pages.

## Что нового в v2

- 5 сценариев тренировок: Daily Mix, Sprint, Marathon, Precision, Weak Spot.
- Custom Mix с выбором игр и числа раундов.
- 8 отдельных мини-игр на разные типы памяти.
- Daily Missions с бонусным XP.
- Комбо-множитель за серию сильных раундов.
- Мастерство и средняя точность отдельно по каждому режиму.
- Отдельный экран аналитики и история последних сессий.
- 12 достижений.
- Адаптивная сложность 1–6.
- Настраиваемый темп показа.
- Настраиваемый отсчёт перед раундом.
- Опциональный таймер ответа (режим давления).
- Включение/выключение отдельных игр в смешанных тренировках.
- Три цветовые темы.
- Настройки анимации, звука, вибрации и Wake Lock.
- Экспорт/импорт прогресса JSON между устройствами вручную.
- Автоматическая миграция базового прогресса из первой версии, если он есть в том же браузере.
- Офлайн-режим после первого открытия.

## GitHub Pages

1. Создай новый репозиторий, например `memory-lab`.
2. Загрузи содержимое этой папки в корень репозитория.
3. Открой Settings → Pages.
4. Выбери Deploy from a branch → `main` → `/root`.
5. Открой выданную HTTPS-ссылку.
6. На iPhone: Safari → Поделиться → На экран «Домой».

## Обновление поверх Memory Lab v1

Можно заменить старые файлы файлами v2. Service Worker использует новый кэш `memory-lab-v2.0.0`, поэтому после публикации закрой установленное PWA и открой снова. Если видна старая версия, один раз открой сайт в Safari и обнови страницу.

Все игровые данные хранятся локально в браузере. Для переноса прогресса на другое устройство используй Настройки → Экспорт прогресса, затем Импорт прогресса на другом устройстве.


## Memory Lab 2.1

Daily Protocol теперь занимает минимум 5 минут активной практики (по умолчанию 6). В настройках можно выбрать 5–20 минут и 9–16 базовых раундов. Если базовые раунды закончились раньше минимального времени, приложение добавляет адаптивные раунды. Время в фоне не засчитывается. Daily Protocol проходит блоки: разогрев, кодирование, рабочая память, пространство и слабое место.
